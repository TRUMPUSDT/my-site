# Rust Tracker

Сайт для слежки за игроками Rust по Steam ID.

**Что внутри**
- Профиль: статус и текущая игра, часы и статистика Rust, баны, уровень, недавние игры.
- Слежка: сервер сам опрашивает список раз в минуту и копит историю онлайна (график по часам и дням недели, журнал входов и выходов).
- Серверы: на каком сервере Rust сидит каждый игрок из слежки (название и онлайн берутся из BattleMetrics).
- Оповещения в Telegram: новые VAC- и игровые баны, вход в Rust (включается у каждого игрока).
- Теги, заметки, группы и кланы со сводным онлайном.
- История ников.
- Сравнение двух игроков и рейтинг по часам, K/D, убийствам, хедшотам, точности.
- Карточка профиля в PNG: скачать или отправить в Telegram.

## Запуск
Сервер есть в двух вариантах, на выбор. Они делают одно и то же, используют один интерфейс, один `.env` и одну базу `data/db.json`.

**Python** (3.9 или новее): `python server.py`
**Node.js** (18 или новее): `node server.js`

Перед запуском: получите Steam Web API Key (https://steamcommunity.com/dev/apikey), скопируйте `.env.example` в `.env` и впишите ключ. Затем откройте http://localhost:3000

Зависимостей нет (ни `pip install`, ни `npm install`). Данные лежат в `data/db.json`: делайте бэкап этого файла.

## Telegram
1. Создайте бота у @BotFather, токен в `TG_BOT_TOKEN`.
2. Напишите боту `/start`.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найдите `"chat":{"id":...}` и впишите число в `TG_CHAT_ID`. Для группы добавьте бота в группу и напишите там сообщение, id будет отрицательным.
4. Перезапустите сервер, на вкладке «Telegram» нажмите «Отправить тест».

## Хостинг
Любой VPS или Render / Railway / Fly.io, команда `python server.py` (или `node server.js`). Диск должен быть постоянным, иначе `data/` пропадёт при перезапуске.
Если сайт открыт в интернет, задайте `ACCESS_PASSWORD`: без него любой посетитель сможет добавлять игроков в слежку и слать картинки в ваш Telegram.

## Ограничения
Используется только публичный Steam Web API.
- Закрытый профиль: нет часов, статистики и текущей игры.
- Адрес сервера Steam отдаёт только при открытом статусе игры. Если сервер не нашёлся в BattleMetrics, показывается IP:порт.
- Онлайн копится только пока сервер запущен и игрок в слежке. Данные за прошлое Steam не отдаёт.
